# 界面中文与默认黑色主题设计规格

**日期：** 2026-10-20  
**状态：** 待审阅  
**范围：** 仅网页界面。不改 Go 后端、README、命令行。

## 1. 目标

1. 网页界面固定为简体中文，不提供语言切换。
2. 支持黑色与浅色两套主题。无记录时使用黑色。顶栏可切换，选择写入浏览器本地存储，刷新后保持。

## 2. 非目标

- 不翻译 README、命令行帮助、服务端日志。
- 不翻译抓包数据：HTTP 方法、协议版本、URL、请求头名称、状态码数字、服务端返回的 `error` 字符串。
- 不改单位：`B` / `kB` / `MB`，`ms` / `s`。
- 不跟随操作系统主题。
- 不引入国际化库，不把文案抽到单独文件。

## 3. 主题行为

主题挂在 `<html data-theme="dark">` 或 `<html data-theme="light">` 上。`:root` 定义黑色变量。`[data-theme="light"]` 覆盖为浅色变量。

存储键为 `localStorage` 的 `httpproxy.theme`，合法值只有 `dark` 和 `light`。

`<script type="module">` 会推迟执行，且 CSS 的 `import` 先于模块正文。因此在 `index.html` 的 `<head>` 里、模块脚本之前，放一段同步脚本：

1. 默认 `dark`。
2. 读取 `httpproxy.theme`。值是 `dark` 或 `light` 时采用该值。
3. 没有记录、值不合法、或访问存储抛错时，保持 `dark`。
4. 把结果写到 `document.documentElement` 的 `data-theme`。

`main.tsx` 不再读取主题。样式首次生效时属性已经就位，已保存的浅色不会先画成黑色。

顶栏按钮放在「下载 CA」左侧。当前为黑色时按钮文案是「浅色」，点击后切到浅色；当前为浅色时文案是「黑色」，点击后切到黑色。点击先更新 `data-theme`，再尝试写入 `httpproxy.theme`。写入失败时当次切换仍然生效，已保存的值保持不变。

`index.html` 的 `lang` 改为 `zh-CN`。`<title>` 保持 `httpproxy`。

## 5. 颜色

两套主题定义同一组变量。选中行使用 `--selected-bg`，文字为 `#ffffff`，主机名使用 `rgba(255, 255, 255, 0.8)`。焦点环、选中筛选文字、标签下划线使用 `--accent`。表格单元格边线和截断提示改为变量，不再写死颜色。

`--danger-bg` 当前没有规则引用。两套主题仍定义它，方便以后使用。

## 6. 涉及文件

- `web/index.html`：`lang`，以及 `<head>` 中的同步主题脚本。
- `web/src/styles.css`：两套变量，选中行、表格线和截断提示改用变量。
- `web/src/components/TopBar.tsx`：中文文案与主题按钮。
- `web/src/components/FilterBar.tsx`：中文文案。
- `web/src/components/FlowTable.tsx`：中文表头、状态文字、空列表。
- `web/src/components/FlowDetail.tsx`：中文标签、字段、正文提示。

`web/src/main.tsx` 不读取主题。`App.tsx` 与 API 类型不改。

## 7. 验证

前端没有测试运行器。完成标准：

1. 在 `web/` 执行 `npm run build`，TypeScript 与 Vite 构建通过。
2. 删除 `httpproxy.theme` 后首次打开，界面为黑色简体中文。
3. 点击「浅色」后刷新，仍为浅色；再点击「黑色」后刷新，回到黑色。
4. 把 `httpproxy.theme` 写成其他字符串后刷新，回到黑色。
5. 表头、筛选、详情、空状态、截断提示均为第 4 节的中文。方法、URL、请求头名称、状态码数字保持原文。
